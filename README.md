# *WAIW* 
**What Am I Watching**
>Um site simples, feito para eu guardar memoria de quais filmes, series e cartoons/desenhos eu assisti
ou estou assistindo. Projeto puramente pessoal e para treino.

Feito utilizando: </br>
**Linguagem**: Javascript | **Runtime**: NodeJS | **Framework**: Express | **Database**: PostgreSQL </br>

Todos esses aprendi enquanto ou pouco antes de fazer o projeto. Eventualmente usarei de algum site de hospedagem para colocar esse projeto no ar, quando fizer, alterarei esse README. </br>
