# *WAIW* 
**What Am I Watching**
>Um site simples, feito para eu guardar memoria de quais filmes, series e cartoons/desenhos eu assisti
ou estou assistindo. Projeto puramente pessoal e para treino.

Criado para ampliar meus estudos, para eu saber como seria fazer a estrutura de um website simples do zero e tentando ao maximo aplicar técnicas/conceitos que são padrões na indústria. </br>

O website contém coisas como: Autenticação e Autorização básicas usando JWT, CRUD para mídias aonde somente admins podem inserir e mudar, mas todos podem ler qualquer uma, e toda a parte de rotas, controllers, views. </br>

>[!NOTE]
>A organização e a aplicação do MVC estão ruins pelo fato de eu ir aprendendo enquanto fazia, inclusive vejo agora como o código está um pouco mal feito. Mas para mim, perceber isso, significa que melhorei enquanto fiz esse projeto.
</br>

Aqui ficará a parte falando sobre a hospedagem do site no futuro, ainda verei isso </br></br>
Feito utilizando: </br>
**Linguagem**: Javascript | **Runtime**: NodeJS | **Framework**: Express | **Database**: PostgreSQL </br></br>
